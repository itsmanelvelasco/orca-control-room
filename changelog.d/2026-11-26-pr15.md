# Release 0.2.0: install and update from release tags

## summary
Control Room is now version 0.2.0. Install it with `orca plugin install itsmanelvelasco/orca-control-room` and move to newer releases with `orca plugin update itsmanelvelasco.control-room`.

## entry
- `orca-plugin.json` version 0.1.0 → 0.2.0; access unchanged.
- README and CLAUDE.md: install picks the newest `vX.Y.Z` tag; `orca plugin update` follows tags; an old `--ref main` install must install again once; on Windows, the `.git` URL if Git fails with `Permission denied`.
- CLAUDE.md: new Releasing section (bump on a branch, Manel merges, tag the merge commit `vX.Y.Z`; changelog folds on `main`).
