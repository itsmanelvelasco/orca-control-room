# Show each Run's shipping line: tasks, workers, PRs and gates

## summary
A new Shipping line panel shows, for each Run, its tasks in build order, the worker on each task, the PR link, and gates A (question) and B (merge). Done tasks fold; with no Runs it says "No runs".

## entry
- `src/views/line/`: `model.ts` builds a plain JSON snapshot (build order, worker per task, PR by Dispatch id from `bot work list`, gate kind from a "Gate A/B" prefix else "merge"); `refresh.ts` reads the CLI one call at a time, at most every 20 s, keeping the last good data; `view.tsx` draws it; `panel.tsx` asks while visible.
- A done task stays open while a gate on it is pending. Workers or gates on a task missing from `task-list` show under "Not on a listed task", never dropped.
- Tests: every Run, task, worker and gate placed right on the fixture set (100%), in the snapshot and in the drawn panel; "No runs"; folding; refresh in turns; untrusted text as plain text.
- `orca-plugin.json` adds the `line` panel (new approval fingerprint; same access).
