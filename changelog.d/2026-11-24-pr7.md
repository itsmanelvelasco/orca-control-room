# Control Room panel loads again

## summary
The panel failed to open for every copy with "Failed to fetch dynamically imported module". The shipping line tab pulled `node:child_process` into the panel; it no longer does, and a test keeps it out.

## entry
- `src/views/line/refresh.ts` takes `isBotId` from `src/cli/commands.ts`, not `src/cli/index.ts`, which imports `node:child_process`, `node:fs` and `node:os`. Orca's panel frame leaves `node:` imports to the browser, which cannot fetch them, so the whole panel failed.
- `test/panel-imports.test.ts` walks every manifest panel's import graph and fails on `node:`, package or missing imports. `orca plugin check` cannot catch this: it renders panels in Node.
- `orca plugin shot` works again; the "shot bug" in PR 6 was this bug.
