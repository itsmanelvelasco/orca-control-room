# Funnel model: each piece of work gets a stage

## summary
Control Room can now place each piece of work (one bot item) in Ideation, Planning, Execution or Shipping, and mark what waits on you. No new view yet; slices 2-5 show it.

## entry
- `src/views/funnel/model.ts`: `buildFunnel()`, pure. Runs join an item by task dispatch, else by a shared PRD link; a Run whose tasks point at two or more items is split; a Run with no item is its own piece.
- PRD links (`claude.ai/artifact/…`, `claude.ai/code/artifact/…`) are read from the item's links, then its description, then its Run's objective. The last link in a text wins.
- Amber: any v1 wait (Needs you, pending gate, blocked or waiting agent) and any failed worker that nothing has replaced. A wait that no piece holds goes to "Unlinked waits".
- A Run on its own whose tasks all finished is done: Shipping, and it leaves 7 days after its newest worker started. The Run and workers of a canceled or aged-out item leave with it. Agent waits attach only through live terminals.
- Fixtures: 33 hand-labelled cases and today's live data with every name swapped. 60 labelled pieces, all stages right. 60 bots build well under 50 ms.
