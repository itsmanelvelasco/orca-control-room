# changelog.d

One file per PR: `<YYYY-MM-DD>-pr<N>.md`. No other branch has that file, so two PRs never conflict here.

```
# <title: what the change does, in plain English>

## summary
One or two sentences. What a user sees.

## entry
- The details worth keeping: files, decisions, what was measured.
```

- Add the file after the PR has a number.
- Do not edit `CHANGELOG.md` on a branch. Entries are folded into it later, on `main`.
