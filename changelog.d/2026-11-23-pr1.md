# Find the Orca CLI on every OS and read its data safely

## summary
Control Room now finds the Orca CLI by itself on Windows, macOS and Linux, and runs it so that it works from inside a plugin. On Windows, `bot list` answers in about 1 s. Only 12 read commands can run.

## entry
- R1 resolver (`src/cli/resolve.ts`): setting, app bin next to `process.execPath`, OS default, PATH; absolute paths only; re-resolve after a failure.
- R2 env (`src/cli/env.ts`): drop `ELECTRON_RUN_AS_NODE`; add `APPDATA`/`LOCALAPPDATA` on Windows, `HOME` on macOS/Linux; 10 s, 16 MB, `windowsHide`, `--json`.
- R3 allow-list (`src/cli/commands.ts`): the 12 PRD commands, ids pattern-checked; a test proves nothing else reaches `execFile`.
- Typed models in `src/model/`; fixtures from a real machine with invented names, plus hand-made cases and env fixtures per OS.
- R5 live: the plugin event reports Claude Code's trust prompt as `waiting` with no reason; `worktree ps` names it (`programStatus` "trust this folder", `agentWait.reason` `agent-trust-workspace`), so trust detection uses `worktree ps`.
