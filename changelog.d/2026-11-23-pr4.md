# Show what waits on you, notify each new wait once, and count waits in the status bar

## summary
A "Waits on you" panel lists, newest first, bot questions set to Needs you, pending gates, and agents that are blocked, waiting or at the folder-trust prompt ("trust this folder"). A click focuses the terminal or opens the workspace. Each new wait shows one desktop notification, and the status bar counts the waits.

## entry
- `src/views/waits/`: `collect.ts` builds the list (same wait from two sources shown once: item and worker agent merge into the gate's row), `refresh.ts` reads every 4 s and after agent events with one CLI call of a kind at a time, `text.ts` cuts untrusted text to one clean line, `panel.tsx` draws it.
- `src/notify.ts`: one notification per new wait, ids kept in storage so a restart does not repeat them; setting `notifyNewWaits` turns them off; status bar text.
- Trust prompt from `worktree ps --agent-wait` (Claude Code `agent-trust-workspace`, Codex `codex-trust-workspace`).
- `src/model/bots.ts`: a bot item's question keeps its `options`.
- Test set `test/fixtures/cases/waits-mixed.json`: 100% recall and precision. No screenshots: `orca plugin shot --scenario` captured Orca's window instead of the panel.
