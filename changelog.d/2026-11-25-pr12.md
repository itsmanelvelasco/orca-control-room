# Funnel graph panel: wires, legend and bot mascots

## summary
**Manel: the new panel means Orca asks you to approve Control Room again before it loads.** A second panel, "Funnel graph", draws each piece of work in its stage column. Dashed wires run from You to each bot, then to its work: amber waits on you, blue is active, grey is done or not started. Each bot shows its Orca mascot or its uploaded picture.

## entry
- New HTML panel `funnel-graph` (`src/views/graph/page/`). The worker builds the layout (`src/views/graph/model.ts`). The page only draws (`draw.js`) and escapes all bot text. Wires stop on reduced motion. The panel has a legend, "What the bots are doing" cards and Unlinked waits. Each column shows 20 cards, then "+N more".
- R9: the worker reads bot pictures (`src/views/graph/mascots.ts`): first the uploaded `avatar.png`, else Orca's mascot from the install (found through `process.execPath`). Each file must be plain, at most 128 KB and its real type. SVGs pass a safety check. A skipped or refused file logs one line, and the bot's initial shows. Files are read again only when their size or mtime changes. The panel gets each bot's picture signature (`graph.pictures`), then one picture per answer (`graph.picture`), only when a signature changed, so every answer stays far below the 256 KiB panel message size. `graph.snapshot` carries the graph.
- The manifest adds a panel, so Orca asks for approval again. The CLI allow-list does not change.
- The page has a meta CSP (only its own files run, pictures only as `data:`, no network). The panel import test follows the HTML entry's scripts. New tests: graph layout, wires, escaping, mascots and the worker requests.
